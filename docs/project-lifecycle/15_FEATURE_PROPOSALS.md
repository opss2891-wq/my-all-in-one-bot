## Recommended Features & Enhancements

### 1. Smart Category Automation (AI Enhancement)
- **Automatic Labels:** Use Gemini to automatically tag conversations based on content (e.g., "Development", "Personal", "Finance").
- **Smart Summaries:** Add a "Summarize Conversation" button in the header to get a quick recap of long chat histories.

### 2. Enhanced Note Management
- **Pinned Notes:** Allow pinning specific important notes to the top of a conversation.
- **Rich Text Support:** Basic markdown support (bold, italics, lists) for better note organization.
- **Note Versions:** Save history of edits for a note to allow reverting changes.

### 3. Advanced Security & Privacy
- **Master Password:** Allow users to set a custom "Master Password" for `crypto-js` encryption instead of the static env-secret, ensuring only they can decrypt their credentials.
- **Self-Destructing Notes:** Option to set a timer on sensitive notes/credentials after which they are automatically deleted.

### 4. Integration & Connectivity
- **Web Clipper:** A browser extension or a specific "Clip Link" feature that extracts full page content into a note.
- **Export/Backup:** Export entire conversations or all notes as PDF/JSON for local backup.

### 5. UI/UX Polish
- **Voice-to-Text:** Add a microphone icon to `MessageInput` to dictate notes using the Web Speech API.
- **Drag & Drop Reordering:** Allow reordering tasks within the Task list via drag-and-drop.
- **Conversation Folders:** Group conversations into folders in the sidebar for better organization.
